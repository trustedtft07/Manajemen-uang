# Aplikasi Keuangan Android (Kotlin)

Aplikasi Android pencatat pemasukan dan pengeluaran sederhana menggunakan Kotlin dengan penyimpanan lokal `SharedPreferences`.

## Fitur
- Tambah transaksi pemasukan dan pengeluaran beserta kategori
- Ringkasan saldo, total pemasukan, dan total pengeluaran otomatis
- Filter riwayat transaksi (Semua / Pemasukan / Pengeluaran)
- Hapus transaksi

## Build & Run
Buka folder project di Android Studio lalu jalankan ke emulator atau perangkat Android (`minSdk 24`, `targetSdk 35`).
